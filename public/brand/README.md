# Partner and wallet marks

- `cx-emblem-green.png`: local color trial of the selected CX Hour Dial mark. Its center square was edited with ImageGen toward NVIDIA green (`#76B900`); `cx-emblem.png` preserves the original white-center mark.
- `meteora.svg`: Meteora's `full-logo-on-dark.svg` from the [official Meteora brand kit](https://github.com/MeteoraAg/brand-kit/tree/main/meteora-v2/full-logo). Keep its gradient and proportions intact.
- `ornn.svg`: Ornn's white wordmark extracted from the inline SVG on the [official Ornn site](https://ornn.com/). The site's CSS color token was resolved to white for standalone use.
- `solana.svg`: The horizontal full logo from [Solana's official brand page](https://solana.com/branding).
- `irys.svg`: The light navigation wordmark from the [official Irys site](https://irys.xyz/). Its CSS color token was resolved to the published fallback color for standalone use.
- `helius.svg`: The primary horizontal orange logo from the [official Helius brand kit](https://www.helius.dev/brand).
- `metamask.svg`: `MetaMask-icon-fox.svg` from the [official MetaMask logo pack](https://metamask.io/assets).
- `phantom.svg`: Phantom's wallet icon bundled in the [Solana Wallet Adapter Phantom adapter](https://github.com/anza-xyz/wallet-adapter/blob/master/packages/wallets/phantom/src/adapter.ts). It uses Phantom's purple and ghost mark.

These third-party marks identify the relevant integration or wallet option. CX does not claim sponsorship by these brands.
